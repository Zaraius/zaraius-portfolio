RL Snake — Reproduction & Improvements

Reproduced and extended a published Deep Q-Learning approach for Snake, then improved the state representation and learning algorithm to surpass the reported baseline.

Role: full software implementation — environment, agent (Double DQN), training loop, logging, and evaluation.

Project summary

Reproduced Sebastianelli et al.'s DQN-based Snake baseline, found practical limitations, and designed a richer 27-dimensional state that improved performance and robustness.

Key technical contributions

  • Reproduction of baseline (11D state) to validate original results and uncover failure modes (looping, self-trapping).
  • Expanded state from ~11D to 27D including 8 directional raycasts (16 dims), 3 food-position dims, 4 one-hot heading dims, and 4 reachability/safety dims computed via bounded BFS.
  • Upgraded learning to Double DQN with a separate target network, hard updates every 500 steps, replay buffer, and decaying epsilon schedule.
  • Network architecture: 3 hidden layers × 512 units; outputs: 3 Q-values (straight, left, right).

Experimental progression & results

Progression: baseline reproduction → diagnose failures → add raycasting & reachability → train Double DQN → evaluate.

  • Best checkpoint: Episode 14,000.
  • 50-game evaluation — Mean: 62.4, Median: 58, Max: 98, Success rate (score ≥ 50): 68%.
  • Result: exceeded the paper's reported best mean (56) using the 27D state + Double DQN improvements.

Implementation details

  • agent.py: Double DQN agent with GPU support, replay buffer, epsilon-greedy policy.
  • game.py: environment implementing 27D state and bounded BFS reachability check.
  • model.py: neural network (512-512-512), ReLU, Adam optimizer.
  • train.py, plot.py, record_best_game.py for training and evaluation.

Engineering lessons

  • Reproduction is valuable — it revealed implementation sensitivities and lower-than-reported baseline variance.
  • Richer state representations (raycasting + reachability) can prevent shortsighted policies that lead to self-trapping.
  • Double DQN reduces Q-overestimation and stabilizes learning in this domain.
